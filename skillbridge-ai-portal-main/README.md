Welcome to SkillBridge AI 🚀

AI-powered placement readiness platform for students and job seekers.

SkillBridge AI helps users prepare for placements by analyzing resumes, generating career roadmaps, recommending skills, and providing AI-powered career assistance.

✨ Features

- 📄 AI Resume Analyzer
  
  - Upload PDF/DOCX resumes
  - Select a target career role
  - Analyze resume content using AI
  - Get resume score and improvement suggestions

- 🛣️ Career Roadmap
  
  - Role-based learning roadmap
  - Beginner, Intermediate and Advanced learning paths
  - Structured monthly learning goals

- 🤖 AI Career Assistant
  
  - Ask career-related questions
  - Get personalized learning and placement guidance

- 🎯 Role-Based Recommendations
  
  - Data Analyst
  - Java Developer
  - Full Stack Developer
  - AI/ML Engineer
  - Cloud Engineer

- 👤 User Authentication
  
  - User registration
  - Login
  - Profile management

⚙️ Installation

1. Clone the repository

git clone <your-github-repository-url>
cd SkillBridge

2. Install frontend dependencies

npm install

3. Install backend dependencies

cd backend
pip install -r requirements.txt

4. Configure environment variables

Create a ".env" file inside the "backend" folder:

GEMINI_API_KEY=your_gemini_api_key

«Never upload your API key or ".env" file to GitHub.»

5. Start the backend

cd backend
python app.py

6. Start the frontend

Open another terminal:

npm run dev

The application will then be available through the local development server.
